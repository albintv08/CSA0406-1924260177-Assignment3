## Requirements
Linux, GCC, GNU binutils and standard system utilities. Selected experiments also use `strace` and `/usr/bin/time`.

## How to use
Open a task folder, compile its C source using the command in that folder's README, and run the executable. Save genuine terminal output and screenshots in the task's `outputs/` folder.

## Evidence and verification
Benchmark values, page-fault counts, memory use and latency depend on the actual machine. Run each experiment yourself and update the task README/report with the measured values. Do not present sample or assumed values as measured results. Be prepared to explain and modify the submitted programs during the verification/viva.
